# Diego Jardim — Projeto Pessoal

Este diretório contém um projeto/portfólio pessoal com uma página estática em HTML.

Descrição
- Site simples para apresentar projetos, habilidades e contato.

Como visualizar
- Abra [diegojardim/index.html](diegojardim/index.html#L1) no navegador.

Arquivos principais
- `index.html`: página inicial.
- `src/css/reset.css` e `src/css/style.css`: estilos.
- `src/images/` (se existir): imagens usadas no site.

Estrutura

- diegojardim/
  - index.html
  - src/
    - css/
      - reset.css
      - style.css
    - images/
